
# ReciPic 🍲📸

ReciPic is a web-based platform that transforms the way we approach cooking.  
Using **image recognition technology**, it scans and identifies ingredients from user-uploaded photos, then suggests a variety of recipes. It helps reduce food waste, simplify meal planning, and spark culinary creativity.

---

## 🚀 Features
- 📷 **Ingredient Detection**: Upload an image of ingredients and let AI recognize them.
- 🍴 **Recipe Suggestions**: Get multiple recipes based on identified ingredients.
- 🌍 **Sustainability Focus**: Reduce food waste by utilizing what’s already in the kitchen.
- 🎨 **User-Friendly UI**: Simple and intuitive interface for quick interactions.
- 📚 **Comprehensive Recipe Database**: Wide range of cuisines and dietary preferences.
- 🎥 **YouTube Integration**: Suggested recipes include relevant cooking videos.

---

## 🛠️ Tech Stack
- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: Python (Flask)  
- **Image Recognition**: MoonDream (vision-language model)  
- **Recipe Generation**: Gemma 2B  

---
## ⚙️ Workflow
1. User uploads an image of ingredients.  
2. Image undergoes preprocessing (resizing, noise reduction, etc.).  
3. **MoonDream** identifies ingredients.  
4. **Gemma 2B** generates recipes based on recognized ingredients.  
5. Recipes (with YouTube video links) are displayed on the UI.
